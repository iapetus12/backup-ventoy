#Redes
- [[PAN]] Red local mas pequenya, tiene una abasto personal. (Ejemplo: dispositivos Bluetoth, moviles, wifi, NFC)
- [[LAN]] Conecta un dispositivo en una area reducida como por ejemplo una oficina, una escuela, una vivienda. 
- [[MAN]] Cubre una area conectando diferentes lans sopbre ella. Pueden conectar diferentes sucursales de una empresa dentro de una misma ciudad. (Fisisicamente)
- [[WAN]] Areas geograficas grandes, como paises o continentes. Internet. 
- [[GAN]] Todas las redes que se conectan entre si. Internet
